# Зелёная кнопка

Скрипт на Python 3.12. Аргумент — имя пакета Android-приложения. Скрипт запускает это приложение на телефоне через adb, находит зелёную кнопку и нажимает её. Если кнопки нет, пишет об этом. На всё есть 10 секунд.

Кнопка ищется по цвету на снимке экрана. Appium и другие автоматизаторы не используются.

Нужны [uv](https://docs.astral.sh/uv/) и adb из Android SDK Platform Tools. Команды ниже одинаковые в PowerShell и в bash. Запускайте их из папки проекта.

## Зависимости

- numpy==2.3.5
- opencv-python-headless==4.13.0.92

Список: `requirements.txt`. Для проверки тестами: `requirements-dev.txt`.

## Запуск

Телефон подключён по USB, экран разблокирован, приложение уже стоит. `adb devices -l` показывает `device`.

```bash
uv run python main.py com.example.app
```

`com.example.app` замените на имя пакета. uv сам возьмёт Python 3.12 и поставит зависимости. Если телефонов несколько, добавьте `--serial` и серийный номер из `adb devices -l`.

Кнопка нажата, код выхода 0:

```text
Зелёная кнопка обнаружена. Команда нажатия выполнена: (220, 305).
```

Кнопки нет, код выхода 1:

```text
Зелёная кнопка не обнаружена за отведённое время (лимит 10 секунд).
```

Другие коды: 2 — не удалось запустить (нет adb, нет телефона, пакет не открылся), 3 — нажатие уже могло уйти, но ответ не пришёл, 130 — остановили до нажатия.

## Проверка задания

Телефон не нужен. В PowerShell перед командой выполните `$env:PYTHONUTF8 = "1"`.

```bash
uv run --with-requirements requirements-dev.txt pytest tests/test_integration.py tests/test_architecture.py -q
```

Три теста закрывают пункты задания:

- `test_complete_subprocess_scenario` — приложение запускается через adb, зелёная кнопка находится, нажатие одно
- `test_absence_with_real_clock_and_processes` — кнопки нет, печатается сообщение, код выхода 1, поиск ограничен 10 секундами
- `test_architecture.py` — детектор не использует Appium и UIAutomator

На телефоне та же команда запуска. Код 0 и нажатая кнопка на экране, либо код 1 и сообщение, что кнопки нет.

## Перед коммитом

Один раз из папки проекта:

```bash
uv run pre-commit install
uv run pre-commit install --hook-type commit-msg
```

Дальше перед каждым коммитом сами запускаются ruff, mypy и проверка сообщения. Сообщение в формате `feat: что сделано`.
