# Правила проекта

Python 3.12; нативные типы, mypy strict, без `from __future__ import annotations`.
Внешние данные проверяются на границе. Внутренние значения — dataclass,
заменяемые зависимости — узкие Protocol. Русские содержательные докстринги.

Не добавлять Appium, UIAutomator, OCR, сервер, очередь или универсальный DI.
Детектор не выполняет I/O. Workflow не импортирует ADB gateway.
Нажатие никогда не возвращается в цикл повторного наблюдения.
Не увеличивать остаток дедлайна до минимального timeout команды.
Ошибки транспорта не выдавать за отсутствие кнопки.

Проверки: pytest, mypy, ruff check/format. Проверка реального устройства
фиксируется отдельно от синтетических тестов и подставного ADB.
